# `src/workflows/delete_database_directory.os`

Workflow безвозвратно удаляет каталог существующей файловой информационной базы 1С.

## Зависимости

- `src/lib/files.os`;
- `src/lib/ibases.os`;
- `src/lib/logger.os`.

## Публичный интерфейс

### `Запустить(ПутьКБазе, ИмяПапкиСпискаБаз)`

Проверяет, что путь заполнен, существует, является не корнем файловой системы, указывает каталог и содержит файл `1Cv8.1CD`. Требует имя папки списка баз. Перед удалением каталога удаляет описание с совпадающим путём только из этой папки или её подпапок в `%APPDATA%\1C\1CEStart\ibases.v8i`. Ставшая пустой папка базы также удаляется, но корневая и непустые папки сохраняются. После этого workflow рекурсивно удаляет каталог базы.

Если проверка не пройдена или файлы заняты другим процессом, вызывается исключение.

## Результат

Каталог базы и всё его содержимое удалены. Резервная копия не создаётся. Совпадающее описание в `ONE_C_IBASES_FOLDER` удалено; записи в других папках сохранены.
