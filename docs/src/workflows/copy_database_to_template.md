# `src/workflows/copy_database_to_template.os`

Workflow копирует файл существующей информационной базы в каталог шаблона.

## Зависимости

- `src/lib/files.os`;
- `src/lib/logger.os`.

## Публичный интерфейс

### `Запустить(ПутьКБазе, ПутьКШаблону)`

Проверяет наличие `<ПутьКБазе>\1Cv8.1CD` и создаёт каталог шаблона при необходимости. Перед заменой существующего шаблона сохраняет его как `1Cv8_backup_1.1CD`, а предыдущую первую копию — как `1Cv8_backup_2.1CD`. Затем копирует исходный файл как `<ПутьКШаблону>\1Cv8.1CD`. Если исходный файл отсутствует, путь шаблона не задан или исходный и целевой файлы совпадают, вызывается исключение.

## Результат

В каталоге шаблона находится копия файла `1Cv8.1CD` переданной базы и не более двух предыдущих версий.
