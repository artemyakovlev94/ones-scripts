# src/workflows/repository_context.os

`Получить(ПутьРепозитория, ИмяВетки)` определяет каталог Git-репозитория и имя задачи. Пустой путь заменяет текущим каталогом запуска, затем получает корень через src/lib/git.os. Пустое имя заменяет текущей веткой. Возвращает структуру ПутьРепозитория, ИмяВетки.

Имя должно быть пригодно для каталога базы. Для detached HEAD или ветки со специальными символами требуется явное имя. Ветка не переключается. Окружение инициализирует вызывающая точка входа.
