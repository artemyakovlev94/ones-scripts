# `src/workflows/download_database_dt.os`

Workflow скачивает ZIP-архив, рекурсивно находит в нём единственный файл `.dt` и копирует его в заданный каталог под заданным именем.

## Публичный интерфейс

### `Запустить(АдресАрхива, КаталогНазначения, ИмяФайлаНазначения)`

- `АдресАрхива` — URL ZIP-архива;
- `КаталогНазначения` — каталог для результата, создаётся при отсутствии;
- `ИмяФайлаНазначения` — конечное имя с расширением `.dt`.

Workflow скачивает архив через `src/lib/download.os`, распаковывает через `src/lib/archive.os`, а поиск и копирование выполняет через `src/lib/files.os`. Временные архив и каталог удаляются как после успеха, так и после ошибки.

Если обязательный параметр не заполнен, имя результата не заканчивается на `.dt` либо архив содержит не ровно один файл `.dt`, выполнение завершается с ошибкой.
