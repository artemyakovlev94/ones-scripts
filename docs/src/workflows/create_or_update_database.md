# `src/workflows/create_or_update_database.os`

Workflow создаёт или обновляет файловую информационную базу worktree, загружает конфигурацию и расширения, регистрирует базу в списке 1С и запускает клиент.

## Зависимости

- `src/lib/process.os`;
- `src/lib/files.os`;
- `src/lib/ibases.os`;
- `src/lib/one_c_database.os`;
- `src/lib/one_c_extensions.os`;
- Vanessa Automation (`vrunner`);
- `ibcmd.exe` требуемой версии и разрядности платформы 1С.

## Публичный интерфейс

### `Запустить(ИмяWorktree, ПутьWorktree, ИмяБазы, ПутьКБазе, ПараметрыОкружения, Расширения, КореньПроекта)`

Выполняет следующие этапы:

1. Проверяет входные данные, каталоги исходников и файлы расширений.
2. Использует переданные имя и путь базы. Для незаполненного имени используется имя worktree, для незаполненного пути — `ONE_C_BASES_PATH\ИмяWorktree`. Отсутствующая база создаётся командой `vrunner init-dev --ibcmd`.
3. Сразу после проверки или создания базы создаёт запись в `%APPDATA%\1C\1CEStart\ibases.v8i` внутри папки `ONE_C_IBASES_FOLDER\_ИмяWorktree`. Если имя базы передано явно и уже найдено во всём файле, регистрация пропускается без изменений. Для вычисленного имени сохраняется обычная логика разрешения конфликтов суффиксами.
4. Для существующей базы загружает конфигурацию через `ibcmd`.
5. Собирает тестовое расширение во временный файл `.temp/ИмяWorktree-tests.cfe`, загружает его в базу через конфигуратор, отключает ограничения расширения и удаляет временный файл. Удаление выполняется также при ошибке сборки, загрузки или настройки. Для `compileexttocfe` и `loadext` режим `--ibcmd` не используется.
6. Загружает расширения из переданного массива структур `name,path` и отключает для каждого безопасный режим и защиту от опасных действий.
7. Запускает клиент новой или существующей базы через `vrunner run --no-wait`. Workflow завершается сразу после запуска и не ожидает закрытия клиента.

При ошибке любого этапа workflow прекращает выполнение и вызывает исключение с названием этапа.

Все команды Vanessa Automation запускаются с `--nocacheuse`, поэтому `vrunner` не добавляет в пользовательский список баз собственную запись с именем текущего проекта. Регистрацией в `ibases.v8i` управляет только `src/lib/ibases.os`.

Для существующей базы workflow передаёт `ONE_C_INFOBASE_USER` и `ONE_C_INFOBASE_PASSWORD` в `ibcmd` как `--user` и `--password`, а в Vanessa Automation — как `--db-user` и `--db-pwd`. При создании новой базы параметры авторизации не передаются.

После загрузки расширения workflow выполняет `ibcmd infobase config extension update` с параметрами `--safe-mode=no` и `--unsafe-action-protection=no`. Для тестового расширения также передаётся `--used-in-distributed-infobase=no`.

Workflow отвечает только за проверку параметров и последовательность этапов. Формирование и выполнение команд платформы вынесено в `src/lib/one_c_database.os` и `src/lib/one_c_extensions.os`.

### `ЗапуститьИзБазыДляСоздания(ИмяWorktree, ПутьWorktree, ИмяБазы, ПутьКБазе, ПараметрыОкружения, Расширения, КореньПроекта, ПутьКБазеДляСоздания)`

Проверяет, что `ПутьКБазеДляСоздания` заполнен и содержит файл `1Cv8.1CD`, после чего запускает ту же цепочку обработки. Если в целевом каталоге нет `1Cv8.1CD`, исходный файл копируется туда. Скопированная база обрабатывается как существующая: исходники основной конфигурации загружаются через `ibcmd`, а для подключения используются `ONE_C_INFOBASE_USER` и `ONE_C_INFOBASE_PASSWORD`.

### `ЗагрузитьТестовоеРасширениеВСуществующуюБазу(ИмяWorktree, ПутьWorktree, ПутьКБазе, ПараметрыОкружения, КореньПроекта)`

Требует существующий файл `1Cv8.1CD` в целевом каталоге, собирает расширение из `WORKTREE_PATH_CFE_TEST`, загружает его в базу, отключает безопасный режим, защиту от опасных действий и использование в распределённой базе, затем удаляет временный CFE. Метод не загружает основную конфигурацию, не регистрирует базу в `ibases.v8i` и не запускает клиент.

### `ЗагрузитьКонфигурациюВСуществующуюБазу(ИмяWorktree, ПутьWorktree, ПутьКБазе, ПараметрыОкружения)`

Требует существующий файл `1Cv8.1CD` в целевом каталоге, импортирует исходники основной конфигурации из `WORKTREE_PATH_CF` командой `ibcmd infobase config import` и обновляет конфигурацию базы данных через `vrunner updatedb --ibcmd`. Метод не загружает расширения, не изменяет `ibases.v8i` и не запускает клиент.
