# `src/workflows/download_cfe_bsp.os`

Workflow скачивает ZIP-архив BSP, извлекает из него единственный файл `.cfe` и сохраняет его под заданным именем.

## Зависимости

- `src/lib/download.os`;
- `src/lib/archive.os`;
- `src/lib/files.os`.

## Публичный интерфейс

### `Запустить(АдресАрхива, КаталогНазначения, ИмяФайлаНазначения)`

- Проверяет заполнение параметров и расширение конечного файла `.cfe`.
- Скачивает архив во временный файл.
- Распаковывает его во временный каталог.
- Рекурсивно находит единственный `.cfe`.
- Копирует файл в каталог назначения под заданным именем.
- Удаляет временные данные при успешном завершении и при ошибке.

Если в архиве нет `.cfe` или их несколько, workflow завершается с исключением.
