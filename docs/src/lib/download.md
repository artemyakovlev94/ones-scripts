# `src/lib/download.os`

Универсальная библиотека скачивания ресурса по HTTP или HTTPS.

## Публичный интерфейс

### `Скачать(АдресURL, ПутьНазначения)`

Выполняет GET-запрос с автоматическим перенаправлением и записывает тело ответа в файл.

- `АдресURL` — полный URL ресурса.
- `ПутьНазначения` — путь к создаваемому файлу.

Некорректный URL и HTTP-ответ вне диапазона `200–299` приводят к исключению. При ошибочном HTTP-ответе частично скачанный файл удаляется.
