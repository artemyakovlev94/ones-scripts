# `src/lib/arguments.os`

Библиотека разбирает единый набор именованных параметров пользовательских скриптов.

## Публичный интерфейс

### `ПрочитатьИменованныеПараметры(Аргументы, ДопустимыеИмена, ПовторяемыеИмена = Неопределено)`

Проверяет, что аргументы переданы парами `--имя значение`, а имена входят в разрешённый набор. Порядок и количество переданных параметров могут быть произвольными. Неизвестные параметры и повторения обычных параметров приводят к исключению.

Для имён из `ПовторяемыеИмена` возвращаемым значением является массив всех переданных значений в исходном порядке. Для остальных параметров значением остаётся одна строка. Повторяемое имя обязано также присутствовать в `ДопустимыеИмена`.
