# src/lib/git.os

Библиотека выполняет команды Git без изменения репозитория. Требуется Git в PATH.

- `ПолучитьКореньРепозитория(Каталог)` — возвращает строку абсолютного пути к корню репозитория.
- `ПолучитьТекущуюВетку(Каталог)` — возвращает строку имени текущей ветки.

При отсутствии репозитория, Git или именованной ветки вызывается исключение. Каталог передаётся как рабочая директория процесса, а не вставляется в команду.
