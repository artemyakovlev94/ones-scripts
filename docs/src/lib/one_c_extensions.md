# `src/lib/one_c_extensions.os`

Библиотека содержит отдельные технические операции с расширениями 1С. Она не определяет порядок загрузки расширений и не управляет пользовательским сценарием.

## Зависимости

- `src/lib/process.os`;
- `src/lib/one_c_database.os`;
- Vanessa Automation (`vrunner`);
- `ibcmd.exe`.

## Публичный интерфейс

### `СобратьВCFE(ПутьКБазе, ПутьКИсходникам, ПутьКCFE, ИмяРасширения, ВерсияПлатформы, Разрядность, Авторизация)`

Собирает исходники расширения в указанный CFE через `vrunner compileexttocfe`.

### `ЗагрузитьИзCFE(ПутьКБазе, ПутьКCFE, ИмяРасширения, ВерсияПлатформы, Разрядность, Авторизация)`

Загружает CFE в базу через `vrunner loadext --updatedb`.

### `ОтключитьОграничения(ПутьКБазе, ИмяРасширения, ВерсияПлатформы, Разрядность, Авторизация, ЭтоТестовоеРасширение)`

Отключает безопасный режим и защиту от опасных действий через `ibcmd`. Для тестового расширения также отключает использование в распределённой базе.

### `ПрочитатьИмяИзИсходников(ПутьКИсходникам)`

Возвращает имя расширения из `Configuration.xml`. Вызывает исключение, если файл или элемент `Name` отсутствует.

### `УдалитьCFE(ПутьКCFE)`

Удаляет CFE, если файл существует.
