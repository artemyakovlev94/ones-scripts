# `src/lib/one_c_extensions.os`

Библиотека содержит отдельные технические операции с расширениями 1С. Она не определяет порядок загрузки расширений и не управляет пользовательским сценарием.

## Зависимости

- `src/lib/process.os`;
- `src/lib/one_c_database.os`;
- Vanessa Automation (`vrunner`);
- `ibcmd.exe`.

## Публичный интерфейс

### `ЗагрузитьТестовоеИзИсходников(ПутьКБазе, ПутьКИсходникам, ВерсияПлатформы, Разрядность, Авторизация, ПоказыватьОкна = Истина)`

Загружает тестовое расширение `ТестированиеТБ` напрямую из исходников в базу через `vrunner compileext`, без создания промежуточного CFE.

### `ЗагрузитьИзCFE(ПутьКБазе, ПутьКCFE, ИмяРасширения, ВерсияПлатформы, Разрядность, Авторизация, ПоказыватьОкна = Истина)`

Загружает CFE в базу через `vrunner loadext --updatedb`.

### `ОтключитьОграничения(ПутьКБазе, ИмяРасширения, ВерсияПлатформы, Разрядность, Авторизация, ЭтоТестовоеРасширение, ПоказыватьОкна = Истина)`

Отключает безопасный режим и защиту от опасных действий через `ibcmd`. Для тестового расширения также отключает использование в распределённой базе.
