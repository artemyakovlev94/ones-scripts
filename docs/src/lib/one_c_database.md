# `src/lib/one_c_database.os`

Библиотека выполняет отдельные технические операции платформы с файловыми информационными базами 1С. Значения окружения и последовательность бизнес-сценария в библиотеке не определяются.

## Зависимости

- `src/lib/process.os`;
- Vanessa Runner 3.x (`vrunner`);
- `ibcmd.exe` установленной платформы.

## Публичный интерфейс

### `СоздатьИзИсходников(ПутьКБазе, ПутьККонфигурации, ВерсияПлатформы, Разрядность, ПоказыватьОкна = Истина)`

Создаёт файловую базу и загружает исходники командой `vrunner infobase init --ibcmd`.

### `ЗагрузитьКонфигурацию(ПутьКБазе, ПутьККонфигурации, ВерсияПлатформы, Разрядность, Авторизация, ПоказыватьОкна = Истина)`

Импортирует исходники через `ibcmd` и обновляет конфигурацию базы через `vrunner infobase update --ibcmd`.

### `ЗапуститьКлиент(ПутьКБазе, ВерсияПлатформы, Разрядность, Авторизация, ПоказыватьОкна = Истина)`

Запускает клиент через `vrunner run enterprise --no-wait`.

### `ПолучитьПутьКIBCmd(ВерсияПлатформы, Разрядность)`

Возвращает путь к `ibcmd.exe` с учётом требуемой разрядности. Вызывает исключение, если утилита не найдена.

### `ДобавитьАвторизациюVanessa(Команда, Процессы, Авторизация)`

Добавляет к команде Vanessa Automation параметры пользователя и пароля, если авторизация включена.

### `ДобавитьАвторизациюIBCmd(Команда, Процессы, Авторизация)`

Добавляет к команде `ibcmd` параметры пользователя и пароля, если авторизация включена.

Для операций с 1С требуется Vanessa Runner 3.x и OneScript 2.0 или новее. Проверка установки: `oscript -version` и `vrunner --version`. Команды Runner 2.x больше не поддерживаются. Runner 3.x не предоставляет параметр `--bitness`: разрядность для его команд выбирает сам Runner. `ONE_C_PLATFORM_BITNESS` продолжает задавать порядок поиска платформы для прямых вызовов `ibcmd`.
