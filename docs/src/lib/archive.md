# `src/lib/archive.os`

Универсальная библиотека распаковки ZIP-архивов.

## Публичный интерфейс

### `РаспаковатьZIP(ПутьКАрхиву, КаталогНазначения)`

Открывает ZIP-архив и извлекает всё его содержимое с восстановлением структуры подкаталогов.

- `ПутьКАрхиву` — путь к существующему ZIP-файлу.
- `КаталогНазначения` — существующий каталог для извлечения.

При ошибке чтения или распаковки закрывает архив и передаёт исключение вызывающему коду.
