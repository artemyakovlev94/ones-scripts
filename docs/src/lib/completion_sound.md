# `src/lib/completion_sound.os`

Библиотека воспроизводит стандартный системный звук Windows после завершения пользовательского скрипта. Внешние PowerShell-модули и регистрация приложения в центре уведомлений не требуются.

## Зависимости

- Windows PowerShell;
- `src/lib/process.os`;
- `src/lib/logger.os`.

## Публичный интерфейс

### `ПолучитьПризнак(ЗначениеНастройки)`

Преобразует `true` и `1` в `Истина`, `false`, `0` и пустое значение — в `Ложь`. Для другого значения вызывает исключение с указанием допустимых вариантов.

### `Воспроизвести(ВоспроизводитьЗвук, ЭтоОшибка = Ложь)`

Если звуковое уведомление включено, воспроизводит стандартный звук Windows `Asterisk` при успешном завершении или `Hand` при ошибке. Ошибка воспроизведения записывается в лог и не изменяет результат основного пользовательского скрипта.
