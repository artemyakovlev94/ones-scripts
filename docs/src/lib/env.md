# `src/lib/env.os`

Библиотека загружает переменные из `config/.env` относительно корня проекта и устанавливает их в среде текущего процесса OneScript.

## Публичный интерфейс

### `Прочитать()`

Читает непустые строки формата `ИМЯ=ЗНАЧЕНИЕ`. Строки, начинающиеся с `#`, игнорируются; одинарные и двойные обрамляющие кавычки удаляются.

Если `config/.env` отсутствует, процедура завершает работу без исключения.

### `ПолучитьЗначение(Имя, ПрежнееИмя = "")`

Возвращает значение переменной среды. Если оно пустое, использует прежнее имя. Возвращаемый тип: строка или Неопределено, если обе настройки отсутствуют. Файлы метод не читает.
