# `src/lib/process.os`

Библиотека синхронно запускает внешние команды и унифицирует обработку ошибок процессов.

## Зависимости

- `src/lib/logger.os`.

## Публичный интерфейс

### `ВыполнитьКоманду(Команда, ОписаниеЭтапа, ПоказыватьОкно = Истина)`

Выводит описание этапа через `logger.os`, запускает команду, ожидает завершения и вызывает исключение при ненулевом коде возврата. При `ПоказыватьОкно = Истина` команда запускается в отдельном окне; при `Ложь` используется скрытый процесс без перенаправления вывода.

### `Аргумент(Значение)`

Возвращает строковое значение в двойных кавычках для безопасной передачи пути или другого значения во внешнюю команду.
