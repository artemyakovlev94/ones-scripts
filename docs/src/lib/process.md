# `src/lib/process.os`

Библиотека синхронно запускает внешние команды и унифицирует обработку ошибок процессов.

## Публичный интерфейс

### `ВыполнитьКоманду(Команда, ОписаниеЭтапа)`

Выводит описание этапа, запускает команду в отдельном окне консоли, ожидает завершения и вызывает исключение при ненулевом коде возврата. Вывод команды остаётся в её консольном окне и использует штатную кодировку запускаемой утилиты.

### `Аргумент(Значение)`

Возвращает строковое значение в двойных кавычках для безопасной передачи пути или другого значения во внешнюю команду.
