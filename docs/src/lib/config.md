# `src/lib/config.os`

Библиотека чтения файла `config/config.json` относительно корня проекта.

## Публичный интерфейс

### `Прочитать()`

Читает JSON с преобразованием объектов в структуры.

Возвращает данные конфигурации или `Неопределено`, если файл отсутствует. Ошибки разбора JSON передаются вызывающему коду.
