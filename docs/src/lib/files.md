# `src/lib/files.os`

Универсальная библиотека операций с файлами и каталогами.

## Публичный интерфейс

### `НайтиЕдинственныйФайл(Каталог, Маска)`

Рекурсивно ищет файл по маске и возвращает его полное имя. Вызывает исключение, если не найдено ни одного файла или найдено больше одного.

### `ОбеспечитьКаталог(ПутьКаталога)`

Создаёт каталог, если он ещё не существует.

### `СкопироватьСКонечнымИменем(ИсходныйФайл, КаталогНазначения, ИмяФайла)`

Обеспечивает наличие каталога назначения и копирует исходный файл под указанным именем.

### `УдалитьКаталогРекурсивно(ПутьКаталога)`

Удаляет каталог вместе со всеми вложенными файлами и подкаталогами. Проверку допустимости удаления должен выполнить вызывающий workflow.
