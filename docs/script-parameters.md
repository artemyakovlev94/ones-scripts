# Входные параметры пользовательских скриптов

Пользовательские скрипты из `scripts/` могут использовать общий набор именованных параметров. Это договорённость публичного API: конкретный скрипт принимает только нужное ему подмножество и не требует передачи пустых неиспользуемых параметров. Порядок параметров не важен.

| Параметр | Назначение |
|---|---|
| `--db-name` | Имя информационной базы 1С. |
| `--db-path` | Путь к информационной базе 1С. |
| `--worktree-name` | Имя worktree. |
| `--worktree-path` | Путь к worktree. |
| `--extension-name` | Имя расширения 1С. |
| `--extension-path` | Путь к расширению 1С. |

`--extension-name` и `--extension-path` допускается повторять для передачи нескольких расширений. Значения связываются попарно в порядке передачи, поэтому количество имён и путей должно совпадать. Для остальных параметров повторение запрещено, если документация конкретного скрипта явно не определяет иное.

Неизвестный параметр должен приводить к понятной ошибке.
