# Входные параметры пользовательских скриптов

Все пользовательские скрипты из `scripts/` запускаются с одинаковым набором именованных параметров. Параметры передаются строго в приведённом порядке.

| № | Параметр | Назначение |
|---:|---|---|
| 1 | `--entity-type` | Контекст запуска: `worktree`, `database` или `extension`. |
| 2 | `--name` | Имя worktree, базы данных или расширения в зависимости от `--entity-type`. |
| 3 | `--path` | Путь к worktree, базе данных или расширению в зависимости от `--entity-type`. |
| 4 | `--one-c-bases-path` | Путь к базе данных. Может быть пустым. |
| 5 | `--edt-projects-path` | Переданное значение не используется: актуальный путь читается из переменной окружения. |
| 6 | `--auxiliary-files-path` | Переданное значение не используется: актуальный путь читается из переменной окружения. |
| 7 | `--worktree-name` | Имя worktree для `entity-type` со значением `worktree` или `database`. |
| 8 | `--worktree-path` | Путь к каталогу worktree для `entity-type` со значением `worktree` или `database`. |
| 9 | `--extensions-json` | JSON-строка с массивом данных о расширениях 1С. |

## Контексты запуска

- `worktree` — `--name` и `--path` описывают worktree.
- `database` — `--name` и `--path` описывают базу данных.
- `extension` — `--name` и `--path` описывают расширение 1С.

Перед использованием контекстных значений скрипт должен проверить `--entity-type`.

## Формат `--extensions-json`

Значение представляет собой JSON-массив объектов:

```json
[
  {
    "key": "test",
    "name": "Test",
    "path": "D:\\test.cfe"
  }
]
```

Поля объекта:

- `key` — пользовательский ключ, по которому скрипт может найти нужное расширение;
- `name` — имя расширения;
- `path` — путь к файлу расширения.

Скрипт должен разбирать значение стандартными средствами JSON и выдавать понятную ошибку при некорректной структуре.
