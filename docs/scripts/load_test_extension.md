# `scripts/load_test_extension.os`

Пользовательская точка входа для прямой загрузки тестового расширения из исходников ветки в существующую файловую базу 1С.

## Используемые параметры

- `--branch-name` — необязательное имя задачи (по умолчанию текущая Git-ветка);
- `--repo-path` — необязательный каталог репозитория (по умолчанию текущий каталог запуска);
- `--db-path` — необязательный путь к существующей базе; по умолчанию используется `ONE_C_BASES_PATH\<branch-name>`.

Остальные параметры общего контракта скрипт не использует.

## Переменные окружения

- `ONE_C_PLATFORM_VERSION`;
- `ONE_C_PLATFORM_BITNESS`;
- `SHOW_COMMAND_WINDOWS`;
- `PLAY_COMPLETION_SOUND`;
- `ONE_C_BASES_PATH` — требуется, если не передан `--db-path`;
- `ONE_C_INFOBASE_USER`;
- `ONE_C_INFOBASE_PASSWORD`;
- `REPOSITORY_PATH_CFE_TEST`.

## Запуск

```powershell
oscript scripts\load_test_extension.os `
  --branch-name "DEV-12345" `
  --repo-path "E:\git\TB" `
  --db-path "D:\db\DEV-12345"
```

## Результат

Тестовое расширение загружено напрямую из исходников в существующую базу и настроено без ограничений. Основная конфигурация и `ibases.v8i` не изменяются, клиент 1С не запускается.

Подробности приведены в [руководстве пользователя](../user-guide/load_test_extension.md).

Репозиторий определяется через Git из текущего каталога запуска (включая его подкаталоги). `--repo-path` задаёт другой каталог репозитория. Имя задачи берётся из текущей Git-ветки; `--branch-name` переопределяет имя базы и папки, не переключая ветку. Для detached HEAD и веток со специальными символами, например `feature/DEV-12345`, передайте `--branch-name DEV-12345`. Требуется Git в PATH. Старые параметры `--worktree-name` и `--worktree-path` заменены новыми.

Настройки путей: `REPOSITORY_PATH_CF` и `REPOSITORY_PATH_CFE_TEST` относительно корня репозитория. Пока новые значения не заданы, используются прежние `WORKTREE_PATH_CF` и `WORKTREE_PATH_CFE_TEST`. Рабочий `config/.env` пользователь обновляет самостоятельно.
