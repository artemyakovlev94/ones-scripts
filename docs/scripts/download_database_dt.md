# `scripts/download_database_dt.os`

Пользовательский скрипт для скачивания выгрузки базы данных 1С из ZIP-архива.

## Запуск

Из корня проекта:

```powershell
oscript scripts\download_database_dt.os
```

Скрипт не использует входные параметры командной строки.

## Переменные окружения

- `DB_DT_ARCHIVE_URL` — обязательный URL ZIP-архива с единственным файлом `.dt`;
- `PLAY_COMPLETION_SOUND` — включает звуковое уведомление об успехе или ошибке.

Переменные читаются из `config/.env`. После успешного выполнения результат находится в `.temp/database.dt` относительно корня проекта. Существующий файл с таким именем заменяется.
