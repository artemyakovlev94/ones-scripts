# `scripts/delete_database_directory.os`

Пользовательская точка входа для безвозвратного удаления каталога файловой базы 1С.

## Используемые параметры

- `--db-path` — обязательный путь к удаляемому каталогу базы.

Остальные параметры общего контракта скрипт не использует.

## Переменные окружения

- `ONE_C_IBASES_FOLDER` — папка, из которой удаляется описание базы;
- `PLAY_COMPLETION_SOUND` — включает звуковое уведомление о результате.

## Запуск

```powershell
oscript scripts\delete_database_directory.os `
  --db-path "D:\db\DEV-12345"
```

## Результат

Каталог `D:\db\DEV-12345` удалён вместе со всем содержимым. Резервная копия не создаётся. Описание с этим путём и ставшая пустой папка базы удаляются из `ONE_C_IBASES_FOLDER` в `ibases.v8i`; корневая, непустые и находящиеся в других ветках папки сохраняются.

Подробности приведены в [руководстве пользователя](../user-guide/delete_database_directory.md).
