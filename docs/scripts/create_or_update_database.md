# `scripts/create_or_update_database.os`

Пользовательская точка входа для создания или обновления файловой базы ветки.

## Используемые параметры

Скрипт использует следующее подмножество [общего контракта](../script-parameters.md):

- `--branch-name` — имя задачи; по умолчанию текущая Git-ветка;
- `--repo-path` — каталог репозитория; по умолчанию текущий каталог запуска;
- `--db-name` — необязательное имя базы в `ibases.v8i`; по умолчанию используется `--branch-name`. Если параметр передан и такое имя уже найдено в файле, список баз не изменяется;
- `--db-path` — необязательный путь к базе; по умолчанию используется `ONE_C_BASES_PATH\<branch-name>`;
- `--extension-name` — имя подключаемого расширения;
- `--extension-path` — путь к файлу подключаемого расширения.

`--extension-name` и `--extension-path` необязательны и могут повторяться. Они связываются попарно в порядке передачи; их количество должно совпадать.

## Переменные окружения

- `ONE_C_PLATFORM_VERSION`;
- `ONE_C_PLATFORM_BITNESS`;
- `SHOW_COMMAND_WINDOWS`;
- `PLAY_COMPLETION_SOUND`;
- `ONE_C_BASES_PATH` — требуется, если не передан `--db-path`;
- `ONE_C_IBASES_FOLDER`;
- `ONE_C_INFOBASE_USER` — требуется для существующей базы;
- `ONE_C_INFOBASE_PASSWORD` — пароль существующей базы, может быть пустым;
- `REPOSITORY_PATH_CF`;
- `REPOSITORY_PATH_CFE_TEST`.

После выполнения база зарегистрирована в списке баз и открыта в клиенте 1С. Подробная команда запуска и описание результата приведены в [руководстве пользователя](../user-guide/create_or_update_database.md).

Репозиторий определяется через Git из текущего каталога запуска (включая его подкаталоги). `--repo-path` задаёт другой каталог репозитория. Имя задачи берётся из текущей Git-ветки; `--branch-name` переопределяет имя базы и папки, не переключая ветку. Для detached HEAD и веток со специальными символами, например `feature/DEV-12345`, передайте `--branch-name DEV-12345`. Требуется Git в PATH. Старые параметры `--worktree-name` и `--worktree-path` заменены новыми.

Настройки путей: `REPOSITORY_PATH_CF` и `REPOSITORY_PATH_CFE_TEST` относительно корня репозитория. Пока новые значения не заданы, используются прежние `WORKTREE_PATH_CF` и `WORKTREE_PATH_CFE_TEST`. Рабочий `config/.env` пользователь обновляет самостоятельно.
