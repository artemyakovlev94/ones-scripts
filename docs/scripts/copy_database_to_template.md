# `scripts/copy_database_to_template.os`

Пользовательская точка входа для сохранения существующей файловой базы 1С как шаблона.

## Используемые параметры

- `--db-path` — обязательный путь к каталогу существующей файловой базы.

Остальные параметры общего контракта скрипт не использует.

## Переменные окружения

- `ONE_C_BASES_TEMPLATE` — каталог назначения;
- `PLAY_COMPLETION_SOUND` — включает звуковое уведомление о результате.

## Запуск

```powershell
oscript scripts\copy_database_to_template.os `
  --db-path "D:\db\DEV-12345"
```

## Результат

Файл `D:\db\DEV-12345\1Cv8.1CD` скопирован в `ONE_C_BASES_TEMPLATE\1Cv8.1CD`. Перед заменой существующий шаблон сохраняется как `1Cv8_1.1CD.bak`, а предыдущая копия сдвигается в `1Cv8_2.1CD.bak`. Другие файлы исходной базы не копируются.

Подробности приведены в [руководстве пользователя](../user-guide/copy_database_to_template.md).
