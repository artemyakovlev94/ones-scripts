# Переменные окружения

Пользовательские скрипты читают настройки из файла `config/.env`. Создайте или обновите его по образцу `config/.env.example` и замените примеры значений параметрами своей рабочей среды.

Рабочий `config/.env` может содержать локальные пути и пароль пользователя 1С, поэтому не добавляйте его в Git.

## Полный пример

```dotenv
BSP_CFE_ARCHIVE_URL=https://example.com/archive.zip

ONE_C_PLATFORM_VERSION=8.3.27.1916
ONE_C_PLATFORM_BITNESS=x64
SHOW_COMMAND_WINDOWS=true
PLAY_COMPLETION_SOUND=false
ONE_C_BASES_PATH=D:\db
ONE_C_BASES_TEMPLATE=D:\db\templatedb
ONE_C_IBASES_FOLDER=DEV
ONE_C_INFOBASE_USER=Administrator
ONE_C_INFOBASE_PASSWORD=
WORKTREE_PATH_CF=src\cf
WORKTREE_PATH_CFE_TEST=src\tests
```

Не каждому скрипту нужны все переменные. Если параметр `--db-path` передан явно, значение `ONE_C_BASES_PATH` для определения базы не используется.

## Применимость

| Переменная | BSP | Создание/обновление базы | База из шаблона | Тестовое расширение |
|---|:---:|:---:|:---:|:---:|
| `BSP_CFE_ARCHIVE_URL` | ✓ | — | — | — |
| `ONE_C_PLATFORM_VERSION` | — | ✓ | ✓ | ✓ |
| `ONE_C_PLATFORM_BITNESS` | — | ✓ | ✓ | ✓ |
| `SHOW_COMMAND_WINDOWS` | — | ✓ | ✓ | ✓ |
| `PLAY_COMPLETION_SOUND` | ✓ | ✓ | ✓ | ✓ |
| `ONE_C_BASES_PATH` | — | условно | условно | условно |
| `ONE_C_BASES_TEMPLATE` | — | — | ✓ | — |
| `ONE_C_IBASES_FOLDER` | — | ✓ | ✓ | — |
| `ONE_C_INFOBASE_USER` | — | для существующей базы | ✓ | ✓ |
| `ONE_C_INFOBASE_PASSWORD` | — | для существующей базы | при необходимости | при необходимости |
| `WORKTREE_PATH_CF` | — | ✓ | ✓ | — |
| `WORKTREE_PATH_CFE_TEST` | — | ✓ | ✓ | ✓ |

«Условно» означает, что переменная требуется только при отсутствии входного параметра `--db-path`.

## Описание переменных

### `BSP_CFE_ARCHIVE_URL`

Прямой URL ZIP-архива БСП для `scripts/download_cfe_bsp.os`. Архив должен содержать ровно один файл `.cfe`.

### `ONE_C_PLATFORM_VERSION`

Полная версия установленной платформы 1С, используемая командами Vanessa Automation и при поиске `ibcmd.exe`.

Пример:

```dotenv
ONE_C_PLATFORM_VERSION=8.3.27.1916
```

### `ONE_C_PLATFORM_BITNESS`

Разрядность платформы. Допустимые значения:

- `x64` — использовать 64-разрядную платформу;
- `x86` — использовать 32-разрядную платформу;
- `x64x86` — сначала искать x64, затем x86;
- `x86x64` — сначала искать x86, затем x64.

### `SHOW_COMMAND_WINDOWS`

Управляет окнами командной строки для `vrunner`, `ibcmd` и других внешних команд:

- `true` или `1` — показывать отдельные окна;
- `false` или `0` — запускать команды скрыто.

Если переменная отсутствует или оставлена пустой, используется `true`.

### `PLAY_COMPLETION_SOUND`

Управляет звуковым уведомлением после завершения любого пользовательского скрипта:

- `true` или `1` — воспроизводить `Asterisk` при успехе и `Hand` при ошибке;
- `false` или `0` — не воспроизводить звук.

Значение по умолчанию — `false`. После звука ошибки скрипт всё равно завершается с ошибочным кодом. Используются стандартные системные звуки Windows, поэтому внешние модули и регистрация приложения в центре уведомлений не требуются.

### `ONE_C_BASES_PATH`

Корневой каталог баз 1С. Если `--db-path` не передан, путь к базе вычисляется как:

```text
ONE_C_BASES_PATH\<worktree-name>
```

Используйте абсолютный путь, например `D:\db`.

### `ONE_C_BASES_TEMPLATE`

Абсолютный путь к каталогу шаблонной файловой базы для `create_or_update_database_from_template.os`. В каталоге обязательно должен находиться файл:

```text
<ONE_C_BASES_TEMPLATE>\1Cv8.1CD
```

Пример: `D:\db\templatedb\1Cv8.1CD`.

### `ONE_C_IBASES_FOLDER`

Имя корневой логической папки в `%APPDATA%\1C\1CEStart\ibases.v8i`, например `DEV`. Это имя папки в списке запуска 1С, а не путь файловой системы. Не добавляйте начальный или конечный символ `/`.

### `ONE_C_INFOBASE_USER`

Имя пользователя существующей базы 1С. Оно обязательно при обновлении существующей базы, работе с копией шаблонной базы и отдельной загрузке тестового расширения.

### `ONE_C_INFOBASE_PASSWORD`

Пароль пользователя базы 1С. Если у пользователя нет пароля, оставьте значение пустым:

```dotenv
ONE_C_INFOBASE_PASSWORD=
```

Не указывайте рабочий пароль в `config/.env.example`.

### `WORKTREE_PATH_CF`

Путь к исходникам основной конфигурации относительно `--worktree-path`.

Например, при:

```dotenv
WORKTREE_PATH_CF=src\cf
```

и `--worktree-path "D:\git\DEV-12345"` исходники ищутся в `D:\git\DEV-12345\src\cf`.

### `WORKTREE_PATH_CFE_TEST`

Путь к исходникам тестового расширения относительно `--worktree-path`. В каталоге должен находиться `Configuration.xml`, из которого скрипт получает имя расширения.

## Диагностика

- Ошибка о незаданной переменной означает, что она отсутствует в `config/.env` или имеет пустое значение.
- Если платформа или `ibcmd.exe` не найдены, проверьте одновременно `ONE_C_PLATFORM_VERSION` и `ONE_C_PLATFORM_BITNESS`.
- Если база не найдена, проверьте `--db-path` либо сочетание `ONE_C_BASES_PATH` и `--worktree-name`.
- Если шаблон не найден, проверьте наличие файла `1Cv8.1CD` непосредственно в `ONE_C_BASES_TEMPLATE`.
