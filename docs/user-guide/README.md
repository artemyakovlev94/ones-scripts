# Руководство пользователя

В этом разделе собраны инструкции по настройке и запуску пользовательских скриптов из каталога `scripts/`.

## Подготовка к запуску

1. Установите [OneScript](https://oscript.io/) и убедитесь, что команда `oscript` доступна в терминале:

   ```powershell
   oscript -version
   ```

2. Откройте терминал в корне репозитория. Все команды из пользовательских инструкций выполняются из корня проекта.
3. Создайте или обновите `config/.env`, используя `config/.env.example` как образец. Укажите рабочие значения необходимых переменных для выбранного скрипта.
4. Не добавляйте `config/.env` в Git: файл может содержать локальные пути и секретные значения.

При запуске скрипты самостоятельно загружают настройки из `config/.env`. Набор необходимых переменных, команда запуска и расположение результата указаны в инструкции каждого скрипта.
