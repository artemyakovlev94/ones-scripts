# Скачивание выгрузки базы данных

Скрипт `scripts/download_database_dt.os` скачивает ZIP-архив, извлекает из него единственный файл `.dt` и сохраняет его как `.temp\database.dt`.

## Требования и зависимости

- установленный OneScript с доступной командой `oscript`;
- доступ по HTTP или HTTPS к прямому URL архива;
- ZIP-архив содержит ровно один файл с расширением `.dt`;
- доступ на запись в каталог проекта.

Скрипт использует внутренние библиотеки скачивания, распаковки ZIP, поиска и копирования файлов. Дополнительная установка этих компонентов не требуется.

## Настройка

Добавьте в `config/.env`:

```dotenv
DB_DT_ARCHIVE_URL=https://example.com/database.zip
PLAY_COMPLETION_SOUND=false
```

Укажите прямую ссылку на ZIP-архив вместо примера.

## Запуск

Выполните из корня проекта:

```powershell
oscript scripts\download_database_dt.os
```

Параметры командной строки не требуются.

## Результат

Файл будет сохранён по пути `.temp\database.dt`. Каталог `.temp` создаётся автоматически, а существующий `database.dt` заменяется. Временный ZIP-архив и каталог распаковки удаляются. Если в архиве нет `.dt` или найдено несколько таких файлов, скрипт завершается с ошибкой.
