# Скачивание CFE БСП

Скрипт `scripts/download_cfe_bsp.os` скачивает ZIP-архив БСП, находит в нём единственный файл с расширением `.cfe` и сохраняет его под стандартным именем `bsp.cfe`.

## Что настроить

Добавьте в `config/.env` переменную:

```dotenv
BSP_CFE_ARCHIVE_URL=https://example.com/archive.zip
```

Вместо примера укажите прямой URL ZIP-архива, содержащего файл `.cfe`. Название переменной и безопасный пример также приведены в `config/.env.example`.

## Как запустить

Выполните из корня проекта:

```powershell
oscript scripts\download_cfe_bsp.os
```

Дополнительные параметры командной строки этому скрипту не требуются.

## Результат

После успешного выполнения файл будет находиться по пути:

```text
.temp\bsp.cfe
```

Путь отсчитывается от корня проекта. Каталог `.temp` создаётся автоматически, если его ещё нет. Если файл `.temp\bsp.cfe` уже существует, он будет заменён скачанным файлом.

Временный ZIP-архив и каталог распаковки удаляются после выполнения. Если архив не содержит `.cfe` или содержит несколько таких файлов, скрипт завершится с ошибкой и не сможет выбрать результат однозначно.
