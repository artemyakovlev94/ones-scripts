# Создание или обновление базы данных 1С

Скрипт `scripts/create_or_update_database.os` создаёт или обновляет файловую базу для worktree, загружает конфигурацию и расширения, добавляет базу в список 1С и запускает клиент.

## Требования

- Windows;
- установленный OneScript с доступной командой `oscript`;
- установленная Vanessa Automation с доступной командой `vrunner`;
- установленная платформа 1С версии и разрядности, указанных в `ONE_C_PLATFORM_VERSION` и `ONE_C_PLATFORM_BITNESS`;
- наличие `ibcmd.exe` в каталоге установленной платформы `Program Files\1cv8\<версия>\bin` или `Program Files (x86)\1cv8\<версия>\bin`;
- права на чтение исходников worktree и файлов `.cfe`;
- права на запись в `ONE_C_BASES_PATH`, корневую `.temp` и `%APPDATA%\1C\1CEStart\ibases.v8i`.

## Зависимости

Скрипт использует `src/lib/env.os`, `src/lib/arguments.os` и `src/workflows/create_or_update_database.os`. Workflow подключает библиотеки запуска процессов, работы с файлами и списком информационных баз. Все внутренние зависимости входят в репозиторий.

## Что настроить

Добавьте рабочие значения в `config/.env` по образцу `config/.env.example`:

```dotenv
ONE_C_PLATFORM_VERSION=8.3.27.1916
ONE_C_PLATFORM_BITNESS=x64
ONE_C_BASES_PATH=D:\db
ONE_C_IBASES_FOLDER=DEV
ONE_C_INFOBASE_USER=Administrator
ONE_C_INFOBASE_PASSWORD=
WORKTREE_PATH_CF=src\cf
WORKTREE_PATH_CFE_TEST=src\tests
```

`WORKTREE_PATH_CF` и `WORKTREE_PATH_CFE_TEST` задаются относительно пути worktree.

`ONE_C_BASES_PATH` используется только при отсутствии параметра `--db-path`.

`ONE_C_INFOBASE_USER` и `ONE_C_INFOBASE_PASSWORD` используются только при обновлении существующей базы. Для новой базы параметры авторизации не передаются. Пароль может быть пустым.

## Как запустить

Из корня проекта выполните команду. Неиспользуемые параметры передавать не нужно, порядок именованных параметров не важен:

```powershell
oscript scripts\create_or_update_database.os `
  --worktree-name "DEV-12345" `
  --worktree-path "D:\git\DEV-12345" `
  --extension-name "ТБ_БСП" `
  --extension-path "D:\tools\bsp.cfe"
```

Чтобы не загружать внешние расширения, не передавайте `--extension-name` и `--extension-path`.

Чтобы использовать отдельные имя и путь базы, передайте необязательные `--db-name` и `--db-path`:

```powershell
oscript scripts\create_or_update_database.os `
  --worktree-name "DEV-12345" `
  --worktree-path "D:\git\DEV-12345" `
  --db-name "DEV-12345-local" `
  --db-path "D:\db\DEV-12345"
```

Для нескольких расширений повторите параметры. Имена и пути связываются попарно в порядке передачи:

```powershell
oscript scripts\create_or_update_database.os `
  --worktree-name "DEV-12345" `
  --worktree-path "D:\git\DEV-12345" `
  --extension-name "ПервоеТестовоеРасширение" `
  --extension-path "D:\Projects\TestExtension1.cfe" `
  --extension-name "ВтороеТестовоеРасширение" `
  --extension-path "D:\Projects\TestExtension2.cfe"
```

Количество `--extension-name` и `--extension-path` должно совпадать. Пустые имена и пути не допускаются.

## Что делает скрипт

1. Использует путь из `--db-path`, а при его отсутствии — каталог `ONE_C_BASES_PATH\ИмяWorktree`.
2. Если каталог базы отсутствует, создаёт базу по выбранному пути.
3. Сразу после проверки или создания базы обновляет `ibases.v8i`. Если `--db-name` передан явно и такое имя уже найдено во всём файле, `ibases.v8i` не изменяется. Иначе в `ONE_C_IBASES_FOLDER` создаются отдельная папка `_ИмяWorktree` и запись с именем из `--db-name` либо `--worktree-name`. Существующие записи и папки не переносятся и не изменяются; при конфликте вычисленных имён используются суффиксы `_1`, `_2` и далее.
4. Загружает исходники основной конфигурации при создании базы либо обновляет ими существующую базу.
5. Собирает и загружает тестовое расширение из `WORKTREE_PATH_CFE_TEST`, затем отключает для него безопасный режим, защиту от опасных действий и использование в распределённой базе.
6. Загружает все расширения из повторяемых пар `--extension-name` и `--extension-path`, отключая для каждого безопасный режим и защиту от опасных действий.
7. Запускает клиент 1С выбранной разрядности с параметром `/itdi` для новой или существующей базы. Скрипт не ожидает закрытия клиента и завершает работу сразу после запуска.

Создание базы и обновление основной конфигурации выполняются в режиме `--ibcmd`. Сборка и загрузка расширений выполняются через конфигуратор без `--ibcmd`, чтобы не замедлять этот этап.

Команды Vanessa Automation запускаются с `--nocacheuse`, поэтому они не создают дополнительную запись `ones-scripts` или запись с другим именем текущего каталога в списке информационных баз.

Команды Vanessa Automation и `ibcmd` запускаются в отдельных окнах командной строки со штатной кодировкой утилит.


## Результат

- файловая база находится по пути из `--db-path` либо, если параметр не передан, в `ONE_C_BASES_PATH\ИмяWorktree`;
- временный файл собранного тестового расширения удалён после загрузки в базу;
- база отображается в списке 1С внутри `ONE_C_IBASES_FOLDER\_ИмяWorktree`;
- клиент 1С запущен с подготовленной новой или существующей базой.

Если команда Vanessa Automation или `ibcmd` завершится с ошибкой, следующие этапы не выполняются.
