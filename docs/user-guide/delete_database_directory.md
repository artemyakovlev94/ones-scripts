# Удаление каталога базы данных

Скрипт `scripts/delete_database_directory.os` безвозвратно удаляет каталог существующей файловой базы 1С.

## Требования

- Windows;
- OneScript с доступной командой `oscript`;
- существующий каталог базы с файлом `1Cv8.1CD`;
- права на удаление каталога и всего его содержимого;
- база не должна использоваться клиентом, сервером или другим процессом.

Платформа 1С и Vanessa Automation не требуются.

## Зависимости

Скрипт использует `src/lib/env.os`, `src/lib/arguments.os`, `src/lib/files.os` и `src/workflows/delete_database_directory.os`. Все зависимости входят в репозиторий.

## Что настроить

Необязательное звуковое уведомление задаётся в `config/.env`:

```dotenv
ONE_C_IBASES_FOLDER=DEV
PLAY_COMPLETION_SOUND=false
```

`ONE_C_IBASES_FOLDER` задаёт логическую папку списка баз 1С, из которой разрешено удалить описание базы.

## Как запустить

```powershell
oscript scripts\delete_database_directory.os `
  --db-path "D:\db\DEV-12345"
```

`--db-path` должен указывать каталог базы, а не файл `1Cv8.1CD`.

## Что делает скрипт

1. Проверяет обязательный параметр `--db-path`.
2. Проверяет, что путь существует, является каталогом и не является корнем файловой системы.
3. Проверяет наличие `<db-path>\1Cv8.1CD`, чтобы не удалить произвольный каталог.
4. Ищет в `ibases.v8i` описание с путём удаляемой базы и удаляет его, только если оно находится в `ONE_C_IBASES_FOLDER` или её подпапке. Если папка базы после этого стала пустой, удаляет и её. Корневая, непустые и чужие папки не изменяются.
5. Рекурсивно удаляет каталог базы и всё его содержимое.

## Результат

Каталог базы удалён без создания резервной копии. Соответствующее описание удалено только из заданной папки списка баз; одноимённые или совпадающие по пути записи в других папках сохранены.
