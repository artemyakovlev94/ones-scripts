# Переменные окружения

Переменные загружаются из `config/.env` библиотекой `src/lib/env.os`. Безопасные примеры значений хранятся в `config/.env.example`.

## Загрузка BSP

### `BSP_CFE_ARCHIVE_URL`

URL ZIP-архива BSP, из которого пользовательский скрипт `scripts/download_cfe_bsp.os` извлекает файл `.cfe`. Результат сохраняется в `.temp/bsp.cfe` относительно корня проекта.

## Платформа и исходники 1С

### `ONE_C_PLATFORM_VERSION`

Версия платформы 1С:Предприятие, например `8.3.27.1916`.

### `ONE_C_PLATFORM_BITNESS`

Разрядность платформы для команд Vanessa Automation. Допустимые значения: `x64`, `x86`, `x64x86` и `x86x64`. Составные значения задают предпочтительный порядок поиска платформы.

### `SHOW_COMMAND_WINDOWS`

Управляет отображением окон консоли для внешних команд. Значения `true` и `1` показывают окна; `false` и `0` запускают команды скрыто. Если переменная не задана, используется `true`.

### `PLAY_COMPLETION_SOUND`

Управляет звуковым уведомлением по завершении пользовательского скрипта. Значения `true` и `1` включают разные системные звуки Windows для успеха и ошибки; `false` и `0` отключают их. Если переменная не задана, используется `false`.

### `ONE_C_BASES_PATH`

Каталог, в котором располагаются базы данных 1С, например `C:\Users\user\Documents`.

### `ONE_C_BASES_TEMPLATE`

Абсолютный путь к каталогу существующей файловой базы, используемой как исходная при запуске `scripts/create_or_update_database_from_template.os`. В каталоге должен находиться файл `1Cv8.1CD`, например `D:\db\templatedb\1Cv8.1CD`. Если переменная не задана или файл отсутствует, скрипт завершается с ошибкой.

### `ONE_C_IBASES_FOLDER`

Имя логической корневой папки для создаваемых баз в списке информационных баз `%APPDATA%\1C\1CEStart\ibases.v8i`, например `DEV`. Значение задаётся как имя без начального и конечного символа `/`; оно не является файловым путём. Внутри этой папки скрипт создаёт отдельную папку `_ИмяWorktree` для записи базы.

### `ONE_C_INFOBASE_USER`

Имя пользователя 1С для подключения к существующей информационной базе. При создании новой базы не используется.

### `ONE_C_INFOBASE_PASSWORD`

Пароль пользователя 1С для подключения к существующей информационной базе. Значение может быть пустым. Рабочий пароль храните только в `config/.env`; в `config/.env.example` оставляйте безопасное пустое значение.

### `WORKTREE_PATH_CF`

Относительный путь от корня Git worktree до каталога исходников основной конфигурации 1С. Например, при значении `src\cf` и корне worktree `D:\project` полный путь будет `D:\project\src\cf`.

Значение не является самостоятельным абсолютным путём и должно объединяться с путём worktree, полученным через входной параметр `--worktree-path`.

### `WORKTREE_PATH_CFE_TEST`

Относительный путь от корня Git worktree до каталога исходников тестового расширения 1С. Например, при значении `src\tests` и корне worktree `D:\project` полный путь будет `D:\project\src\tests`.

Значение не является самостоятельным абсолютным путём и должно объединяться с путём worktree, полученным через входной параметр `--worktree-path`.
