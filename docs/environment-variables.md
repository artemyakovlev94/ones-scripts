# Переменные окружения

Переменные загружаются из `config/.env` библиотекой `src/lib/env.os`. Безопасные примеры значений хранятся в `config/.env.example`.

## Платформа и исходники 1С

### `ONE_C_PLATFORM_VERSION`

Версия платформы 1С:Предприятие, например `8.3.27.1916`.

### `ONE_C_BASES_PATH`

Каталог, в котором располагаются базы данных 1С, например `C:\Users\user\Documents`.

### `WORKTREE_PATH_CF`

Относительный путь от корня Git worktree до каталога исходников основной конфигурации 1С. Например, при значении `src\cf` и корне worktree `D:\project` полный путь будет `D:\project\src\cf`.

Значение не является самостоятельным абсолютным путём и должно объединяться с путём worktree, полученным через входной параметр `--worktree-path`.

### `WORKTREE_PATH_CFE_TEST`

Относительный путь от корня Git worktree до каталога исходников тестового расширения 1С. Например, при значении `src\tests` и корне worktree `D:\project` полный путь будет `D:\project\src\tests`.

Значение не является самостоятельным абсолютным путём и должно объединяться с путём worktree, полученным через входной параметр `--worktree-path`.
